# CrypticEngine

CrypticEngine is a modern web-based application for exploring classical cryptographic techniques through an interactive interface. It enables users to encrypt and decrypt text using well-known cipher algorithms while building an intuitive understanding of how these methods work.

The project is designed for students, developers, and security enthusiasts who want a practical introduction to encryption concepts without unnecessary complexity.

---

## Features

- Text-based encryption using classical cipher techniques  
- Decryption of encoded messages in real time  
- Structured reference for understanding cipher logic  
- Responsive and clean user interface  
- Modular architecture for easy extension  

---

## Supported Ciphers

- Caesar Cipher  
- Vigenère cipher
- XOR
- Base64

---

## Tech Stack

- **Frontend:** React and React Router 
- **Styling:** Tailwind CSS  
- **Icons:** React Icons  
- **Design** StitchUI

## Installation

Clone the repository and install dependencies:

```bash
git clone https://github.com/Agontuk19/CrypticEngine.git
cd CrypticEngine
npm install
npm run dev
```

## Design Philosophy

CrypticEngine focuses on clarity and usability:
	•	Keep cryptographic concepts simple and visual
	•	Provide immediate feedback through interaction
	•	Maintain clean separation of logic and UI
	•	Ensure scalability for adding new algorithms
